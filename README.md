# The DSA App

This project's purpose is to challenge myself into making almost everything from scratch (for now this is my biggest project I've been doing to date).

The dsa application is a GUI application which aims to teach everything regarding Data Structures and Algorithms. It is interactable and works on any machine, even old 32-bit machines.

It's made using ImGUI (GUI), GLFW (Window), glad (OpenGL loader), nholmann/json (json), gtest or Catch2 (for testing, I really need to implement this for Core), all in C++17.

You can also add your own language to this by copying an existing json from locale and modifying it as you please.

Once the project is finished I'll create a documentation about both Core and UI.

## How to build
Run any script that starts with *build-* that works on your machine. All vendors (except glad) are git submodules. <br>
(ps1 - Powershell Windows) <br>
(sh - Shell Unix)
